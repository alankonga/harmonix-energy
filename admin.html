How this works

Add your projects, equipment, prices and packages below. This page does not change the live website by itself. It builds a new data.js file for you to paste into GitHub.

  1. Fill in the forms below. Your work is kept as a draft in this browser.
  2. Scroll to the bottom and press Copy data.js.
  3. On GitHub, open data.js, click the pencil, select all, paste, and Commit changes.
  4. For project photos, first upload them to GitHub (for example into images/projects/), then type the path in the form, such as images/projects/clinic.jpg.
